# Chrome Web Store assets

Generated by `npm run docs:screenshots` (from `app/`) — do not edit by hand.
Source: `app/e2e/docs/store-assets.spec.ts`, which frames the real UI captures
from `docs/images/`.

| File | Size | Dashboard field |
|---|---|---|
| `icon-128.png` | 128×128 (96×96 artwork + 16 px transparent padding) | Store icon |
| `screenshots/en/*.jpg` | 1280×800 | Screenshots — English (default locale) |
| `screenshots/pt_BR/*.jpg` | 1280×800 | Screenshots — Português (Brasil) |
| `promo-small-440x280.jpg` | 440×280 | Small promo tile |
| `promo-marquee-1400x560.jpg` | 1400×560 | Marquee promo tile (required to be featured) |

Screenshots are numbered in the intended upload order (the store accepts up
to 5). Promo tiles cannot be localized, so they are English only. Requirements:
[developer.chrome.com/docs/webstore/images](https://developer.chrome.com/docs/webstore/images).

The extension UI is Portuguese-only for now, so the English screenshots show
English captions over a Portuguese interface.
